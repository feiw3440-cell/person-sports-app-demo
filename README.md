# 专体 PERSON SPORTS · 高保真交互 Demo（APP 端）

体育项目发现、专业体育内容、运动员展示、导师教学与培养、赛事及机构连接平台的可运行前端演示。
**五大主页面已按用户提供的高保真原型图（蓝白国际体育科技风）一比一还原**（摄影素材裁切自原型图，见 `public/img/`）。
**本 Demo 不包含商城、商品、商家、推荐商品、佣金或任何交易流程**；原型中的订单/钱包/VIP/积分入口为带范围提示的原型占位（是否纳入后续需求待确认）。

## 技术栈

| 项 | 选型 | 说明 |
|---|---|---|
| 构建 | Vite 5 | 极简启动与构建，无后端依赖 |
| 框架 | React 18 + TypeScript | 组件化实现导航/卡片/榜单行/筛选器/空状态 |
| 路由 | react-router-dom 6（HashRouter） | 二级页跳转与返回，支持静态部署 |
| 状态 | Zustand（含 localStorage 持久化） | 当前身份指针、关注/点赞/收藏、消息已读、申请状态 |
| 数据 | 本地模拟数据（`src/data/db.ts` + `src/services/api.ts`） | 数据与组件分离，未来可整体替换为真实 API |

## 本地启动

```bash
cd app
npm install     # 首次安装依赖
npm run dev     # 启动开发服务器（默认 http://localhost:5173）
```

> 提示：如遇"改代码不生效"，先确认没有残留的旧 vite 进程占用 5173 端口（`netstat -ano | findstr 5173`）。

生产构建与预览：

```bash
npm run build   # 构建产物输出至 dist/
npm run preview # 本地预览构建产物
```

- 移动端优先，设计基准 **393 × 852**；桌面浏览器打开时页面内容限宽居中，模拟手机屏。
- 推荐用浏览器开发者工具的手机模拟（iPhone 12/13/14 Pro ≈ 393×852）体验。

## 目录结构

```
app/
├─ src/
│  ├─ main.tsx / App.tsx        # 入口与路由（21 个页面路由）
│  ├─ styles/                   # 设计令牌（tokens.css）+ 全局样式（app.css）
│  ├─ types.ts                  # 演示数据类型定义（不含商城实体）
│  ├─ data/db.ts                # 本地模拟数据库（全部标注为演示数据）
│  ├─ services/api.ts           # 模拟服务层：榜单计算/搜索/关注流
│  ├─ store/store.ts            # 全局状态：身份切换不丢失任何数据
│  ├─ components/               # Icon(线性图标)/ui(基础组件)/cards(业务卡片)
│  └─ pages/                    # 5 主导航页 + 7 详情页 + 身份/授权/管理/状态/关于
└─ docs/                        # 功能清单、模拟数据说明、自测报告
```

## 核心演示路径（对应验收路径）

1. 首页 → 项目卡 → 项目详情 → 相关内容/导师
2. 首页/发现 → 内容详情 → 发布者主页 → 课程详情
3. TOP → 榜单类别 → 切换综合/专业/人气 → 人物或项目详情
4. 我的 → 身份管理 → 切换身份 → 回到对应内容状态（数据不丢失）
5. 我的 → 师徒关系 → 授权详情 → 项目/期限/再授权示例

## 设计说明

- 品牌框架色采用 PRD §9.2（品牌深蓝 #12345B / 交互蓝 #2872B8 / 浅灰 #F3F6FA），
  项目与榜单类别强调色采用《年轻配色》视觉稿方向（已确认融合方案）。
- 榜单三模式口径：综合榜 = 专业 60% + 影响力 40%（**示意权重，正式规则待确认**）；
  专业榜基于核验成绩/资质（未核验数据明确标注）；人气榜由关注/观看/收藏/评论构成（非仅按点赞排序）。
- 导师等级"认证/高级/体系导师"为演示占位名称，准入与晋级标准待确认。

## 已知限制

- 视频播放、支付、真实报名、消息推送、后端与真实数据接入均不在范围内。
- 授权模板、跨级授权、审批/撤销流程、未成年人规则、综合榜正式权重等待产品负责人确认。
