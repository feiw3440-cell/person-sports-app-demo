# 02 · 接口契约（REST /v1 V1）

> Base URL（本地 Demo）：`http://127.0.0.1:8787/v1`。APP 与 PC 指向同一地址（实体手机用局域网 IP，见 04-迁移方案 §5）。

## 1. 全局约定

- **鉴权**：`Authorization: Bearer <access_token>`（JWT，30 分钟）；刷新用 `POST /auth/sessions/refresh`（refresh_token 可撤销）。载荷含 `account_id / identity_id / org_id / perm_version`，**仅作上下文，不作为授权事实**。
- **幂等**：所有会产生创建的 `POST` 要求 Header `Idempotency-Key: <uuid>`；重放返回原响应 + `Idempotency-Replayed: true`。
- **乐观锁**：`PATCH` 与状态动作请求体携带 `version`；不匹配返回 `409 VERSION_CONFLICT`（附服务端最新对象，客户端刷新重试）。
- **状态动作**：`POST /v1/<resource>/:id/actions`，体 `{ action, reason?, version }` —— 状态只能经动作迁移（服务端状态机校验），禁止直接 PATCH status。动作记录操作者/时间/原因/前后状态 → audit_logs。
- **响应封装**：成功 `{ data, meta? }`；错误 `{ error: { code, message, details? } }`。
- **分页**：`?page&page_size`（默认 20，最大 100），`meta: { total, page, page_size }`；游标分页为后续优化项。
- **对象标准字段**：`id, status, version, created_at, updated_at`。
- **错误码**：`INVALID_CREDENTIALS(401) / TOKEN_EXPIRED(401) / FORBIDDEN(403) / NOT_FOUND(404) / VERSION_CONFLICT(409) / IDEMPOTENCY_CONFLICT(409) / STATE_ILLEGAL(422) / VALIDATION_FAILED(422) / RATE_LIMITED(429)`。
- **权限拒绝语义**：越权一律 `403 FORBIDDEN`，不区分"不存在"与"无权"，防探测。

## 2. 认证与上下文

| 方法/路径 | 说明 |
|---|---|
| `POST /auth/sessions` | 登录 `{ login_name, password, client }` → `{ access_token, refresh_token, expires_in, me }` |
| `POST /auth/sessions/refresh` | `{ refresh_token }` → 新令牌对（旧 refresh 作废，可检测重用） |
| `DELETE /auth/sessions/:id` | 登出/撤销会话 |
| `POST /auth/context` | 切换身份/组织 `{ identity_id?, org_id? }` → 签发新上下文令牌；**客户端须清空越权缓存**（契约行为约定） |
| `GET /me` | 账号 + identities + memberships（含各组织内角色） + 当前权限摘要 `perm_version` |
| `PATCH /me` | 改本人资料（display_name/avatar/phone…）`{ version }` |

## 3. 设置（五作用域）

| 方法/路径 | 说明 |
|---|---|
| `GET /me/settings` | 按 scope 合并返回：`[{ scope, org_id?, device_id?, prefs, version, updated_at }]` |
| `PATCH /me/settings` | `{ scope, org_id?, device_id?, prefs(部分键), version }` → 409 冲突；成功返回新版本。**账号/隐私/通知改动触发 Outbox 事件同步另一端；组织级不覆盖个人级；设备级不跨端** |
| `GET /me/privacy/:field` | 敏感字段授权判定（服务端每次读取生效，不落端侧缓存） |

## 4. 组织

| 方法/路径 | 权限要点 |
|---|---|
| `GET /organizations` | 本人 memberships 关联的组织 |
| `GET /organizations/:id` | 本组织成员或平台角色 |
| `GET /organizations/:id/members` | org_admin/coach → 本组织；平台 → 全部 |
| `POST /organizations/:id/invitations` | org_admin；`{ login_name, role, position, valid_until }` → pending 邀请 |
| `POST /memberships/:id/actions` | `accept`（本人）/ `decline`（本人）/ `revoke`（org_admin） |

## 5. 体育项目中心

| 方法/路径 | 权限要点 |
|---|---|
| `GET /projects?keyword&category&tag&status&page` | 登录即可读 active；platform 读全状态 |
| `GET /projects/:id` | 含分类/标签/分支/竞赛小项/关联业务计数 |
| `POST /projects`、`PATCH /projects/:id` | 仅 platform_ops/platform_admin；PATCH 生成 project_versions |
| `POST /projects/:id/actions` | `activate` / `deprecate`（软停用） |
| 子资源 | `GET/POST/DELETE /projects/:id/categories|tags|branches`；`GET/POST /projects/:id/competition-units`；`GET /projects/:id/versions`（历史） |

## 6. 人员与人才

| 方法/路径 | 权限要点 |
|---|---|
| `GET /people?kind&keyword&project_id&org_id&verify&page` | org_admin/coach → 本组织成员档案；platform → 全部；隐私字段按 visibility + 服务端授权裁剪 |
| `GET /people/:id` | 档案+项目关联+资质+状态历史 |
| `PATCH /people/:id` | 本人；敏感字段改动按 privacy scope 校验 |
| `POST /credentials/:id/actions` | `submit`（本人）/ `approve` / `reject` / `request_resubmit`（reviewer/platform_admin）→ 审计 |
| `POST /people/export` | org_admin/platform；**单独授权 + 必写 audit_logs**，异步任务返回下载 ID |

## 7. 教学与训练

| 方法/路径 | 权限要点 |
|---|---|
| `GET/POST /courses`、`GET/PATCH /courses/:id` | 写：mentor(本人)/org_admin(本组织)；状态动作用 actions |
| `POST /courses/:id/actions` | `submit_review` / `publish` / `pause` / `archive`（状态机 §9） |
| `GET /courses/:id/classes`、`POST /courses/:id/classes` | 课程负责人 |
| `POST /enrollments` | 学员本人（Header Idempotency-Key）→ pending |
| `GET /enrollments?course_id&status` | 学员看本人；mentor/org_admin 看本课程/组织 |
| `POST /enrollments/:id/actions` | `approve` / `reject`（mentor/org_admin）/ `cancel`（本人，限 pending）/ `complete` |

| `GET/POST /training-plans`、`GET/POST /training-records` | mentor 与本人学员；记录含操作者 |

## 9. 师徒与授权

| 方法/路径 | 权限要点 |
|---|---|
| `GET /mentorships` | 本人相关（双视角） |
| `POST /mentorships` | 导师发起（或学员申请，导师确认） |
| `GET/POST /authorizations`、`GET /authorizations/:id/chain` | 链路可视化（导师→授权教练→学员） |
| `POST /authorizations/:id/actions` | `submit`（grantor）/ `approve`（grantor + platform reviewer 双审）/ `reject` / `revoke`（必填 reason）/ 到期由服务端定时任务置 `expired` 并通知双方 |

## 11. 消息、工作台与分析

## 12. 系统管理（platform_admin）

`GET/POST /admin/accounts`（检索/停用）、`GET /admin/roles`、`GET /admin/audit-logs?action&actor&resource&page`、`GET /admin/dictionaries`、通知模板/字典配置 CRUD —— 高风险操作均二次确认 + 审计（客户端与服务端双重确认，服务端为准）。

## 13. 媒体

`POST /media`（multipart，本地存 `server/data/uploads/`）→ `{ id, url }`；`GET /media/:id` 鉴权流式返回。云存储后续经适配层替换，契约不变。
