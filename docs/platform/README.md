> 本目录文档为阶段2–5实施的约束性契约；与 APP 端 `docs/`（功能清单/模拟数据说明/自测报告）互不覆盖。

## 0. 已确认决策记录（2026-11-18，产品负责人裁决）

| # | 决策 | 结论 |
|---|---|---|
| ① | GitHub 仓库可见性 | 现有 `person-sports-app-demo` 转**私有**，在本仓库内增量扩展（APP 原结构不动）；GitHub Pages 演示随之下线（已确认接受） |
| ② | 后端栈 | **Fastify + better-sqlite3**（Node 24 + TypeScript），零外部依赖，SQLite 为唯一权威事务库 |
| ③ | PC UI | **Ant Design 5** + ConfigProvider 主题定制（品牌 #12345B / #2872B8 / #F3F6FA，白卡片）；不替换 React/TS/Zustand 技术栈 |
| ④ | APP 接入深度 | 闭环相关（登录/报名/消息/身份/组织）走共享 API；浏览类数据（榜单/内容/项目展示）暂留本地 Mock 并保留 isMock 标注；APP 新增数据一律从共享 API 读取 |

## 1. 总体架构

```
┌──────────────────────┐      ┌──────────────────────┐
│  APP（现有，不重写）   │      │  PC 工作台（新增）     │
│  Vite+React18+TS     │      │  Vite+React18+TS     │
│  HashRouter          │      │  AntD5 + BrowserRouter│
│  闭环交互→http.ts     │      │  全量走 API           │
└──────────┬───────────┘      └──────────┬───────────┘
           │      同一 API / 同一数据库    │
           └────────────┬────────────────┘
                        ▼
        ┌───────────────────────────────┐
        │  server/（新增，唯一权威后端）   │
        │  Fastify :8787 /v1/*           │
        │  JWT 短令牌 + 可撤销刷新会话     │
        │  RBAC+数据范围逐请求校验         │
        │  状态机 / 幂等键 / 版本乐观锁    │
        │  审计 / Outbox 事件 / 设置五域   │
        └──────────────┬────────────────┘
                       ▼
        ┌───────────────────────────────┐
        │  SQLite（server/data/app.db）  │
        │  迁移脚本 + 演示种子数据         │
        │  媒体文件：本地开发目录           │
        └───────────────────────────────┘
```

- 禁止：两端各自建库 / localStorage 冒充共享 / 静态 JSON 互通 / 前端隐藏当权限。
- APP 的 `src/data/db.ts` 与 `services/api.ts` 保持现状并继续标注 Mock；其中函数签名是既定的 API 替换边界（见 `app/docs/模拟数据说明.md` §4）。
