# 04 · 迁移与回滚方案（APP 兼容 + 数据库 + 种子 V1）

## 1. 总原则

- **APP 不可破坏**：现有导航/视觉/图标/路由不动；改动限于"新增文件 + 单点接线"；每阶段交付含 APP 回归结果（构建通过 + 五导航可达 + 核心路径走通）。
- **数据库唯一权威**：仅 `server/data/app.db` 一份；APP/PC 不建平行业务库；localStorage 只存令牌与端内互动状态（现键 `zhuan-ti-demo-v2` 保留原语义，新增 `zhuan-ti-auth-v1` 存会话）。
- **演示/正式隔离**：种子数据全部带 `demo: true` 标记与界面"演示数据"标注；演示账号仅本机有效。

## 2. 数据库迁移与回滚

- 目录：`server/db/migrations/001_init.sql …`，配 `server/db/migrations/down/001_init.down.sql`。
- 执行器：启动时按 `schema_migrations` 顺序应用未执行迁移（启动门禁：迁移失败→服务拒绝启动，不半跑）。
- 命令：`npm run db:migrate` / `db:rollback`（执行 down 脚本并删记录行）/ `db:reset`（**删除 app.db → 全量重建 → 灌种子**，仅用于本地 Demo 重置演示数据）。
- 备份门禁：任何不可逆操作前先 `db:backup`（复制 `app.db → backups/app-<ts>.db`）；禁止无备份执行删除历史/重置用户数据的操作。
- SQLite 文件即备份单元；阶段5 提供"备份-迁移-校验-回滚"演练说明。

## 3. APP 最小接入步骤（阶段2 起，逐项可回滚）

| 步骤 | 改动 | 回滚方式 |
|---|---|---|
| A1 | 新增 `app/.env.example`（`VITE_API_BASE=http://127.0.0.1:8787`，无密钥） | 删文件 |
| A2 | 新增 `src/services/http.ts`：fetch 封装（token 注入、Idempotency-Key、409 冲突处理、403 统一提示） | 删文件（无人引用前） |
| A3 | 新增 `src/pages/LoginPage.tsx` + 路由 `/login`（APP 首个真实登录；未登录仍可浏览 Mock，报名等闭环动作触发登录引导）——**不改既有导航结构** | revert 单 commit |
| A4 | 赛事详情/课程详情报名按钮：toast 占位 → `POST /registrations|/enrollments` + 服务端状态显示（保留原 UI） | revert 单 commit |
| A5 | 消息页顶部新增"服务端通知"区块（`GET /notifications`），Mock 列表保留并标注 | revert 单 commit |
| A6 | 身份管理页接 `GET /me` 显示共享账号与组织（现 6 演示身份保留） | revert 单 commit |
| A7 | 我的页设置入口 → 接 `GET/PATCH /me/settings`（账号/隐私/通知三域先行） | revert 单 commit |

每步一个独立 commit，主题注明 `[app-min-integration]`；任一步失败可单独 revert 不牵连其他。

## 5. 本地启动链路（README 将按此编写）

```
克隆仓库 → npm install（根工作区，server/pc/packages + app 各自 install）
→ npm run db:migrate && npm run db:seed（初始化/重置：db:reset）
→ npm run dev:server（Fastify :8787）
→ npm run dev:pc（:5174） 与 npm run dev:app（:5173）
```

- 双端默认本机浏览器；实体手机：手机与电脑同局域网，APP 的 `VITE_API_BASE` 改为 `http://<电脑局域网IP>:8787`（vite server.host 已开启；**不得用 localhost 指向开发机**）。PC 端为桌面浏览器场景，不涉及手机访问。
- `.env.example` 提供全部变量模板，无真实密钥；`server/data/`（数据库+上传件）不入 Git（.gitignore）。
- 停止/重置：Ctrl-C 停进程；`db:reset` 恢复初始演示态。

## 6. 风险与缓解

| 风险 | 缓解 |
|---|---|
| APP 改动破坏既有体验 | 新增文件+单点接线；每步独立 commit；阶段门含 APP 回归 |
| Mock 与真实数据混淆 | 未接 API 的页面保留"模拟数据"标注；接 API 的数据不再标 Mock；种子全带 demo 标记 |
| localStorage 双键语义混淆 | 旧键=端内互动演示态；新键=会话。互不读写 |
| SQLite 并发写 | better-sqlite3 同步事务 + WAL；Demo 规模单进程无瓶颈；线上换 PG 仅替换驱动层（契约不变） |
| 实体手机误用 localhost | README 明确局域网 IP 配置 + 启动时 server 打印本机 IP 提示 |
| 迁移不可逆 | up/down 成对 + 备份门禁 + db:reset 仅限演示库 |
