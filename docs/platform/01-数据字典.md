# 01 · 数据字典（SQLite 权威库 V1）

> 库文件：`server/data/app.db`（better-sqlite3，WAL 模式）。
> 全库约定：主键 `id TEXT`（服务端生成的短随机 ID）；每业务表含 `created_at TEXT`、`updated_at TEXT`（ISO 8601 本地 UTC 字符串）、`version INTEGER`（乐观锁，写时 +1）；外键显式；时间一律服务端生成。
> 枚举值即契约：客户端不得自行扩展状态值。`schema_migrations` 表记录已应用迁移。
> **本库为唯一权威数据源；APP/PC 均无第二业务库。**

## 1. 认证与身份域

### accounts
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT PK | |
| login_name | TEXT UNIQUE | 登录标识（演示账号如 `demo@local`） |
| password_hash | TEXT | scrypt 加盐哈希（本地 Demo 自实现，无外部依赖） |
| display_name | TEXT | 姓名/昵称 |
| avatar_url | TEXT | 本地媒体路径 |
| phone | TEXT? | 联系方式（演示脱敏） |
| locale / timezone | TEXT | 账号级设置默认值 |
| status | TEXT | `active` / `disabled` |

### refresh_sessions
会话（可撤销）。`id, account_id FK, client('app'|'pc'), token_hash, expires_at, revoked_at?, revoked_reason?`；访问令牌为短期 JWT（默认 30 分钟），载荷含 `account_id + identity_id + org_id + perm_version`（权限上下文），**角色声明不作为授权事实，逐请求仍查库**。

### identities（身份，账号多对身份）
`id, account_id FK, identity_type, label, status('active'|'pending'|'rejected'|'disabled')`；`UNIQUE(account_id, identity_type)`。
`identity_type ∈ regular | student | athlete | coach | mentor | org_admin | org_member | event_organizer | content_editor | reviewer | platform_ops | platform_admin`

### credentials（资质，挂接身份）
`id, identity_id FK, kind(等级/证书名), source(来源), evidence JSON, status('draft'|'submitted'|'under_review'|'approved'|'rejected'|'resubmitted'), valid_until?, reviewed_by?, reviewed_at?, reason?`

## 2. 组织与权限域

### organizations
`id, name, type('club'|'school'|'venue'|'association'), parent_id?, region, intro, contact JSON, status, version`
### memberships（组织成员关系）
`id, account_id FK, org_id FK, role('org_admin'|'coach'|'member'|'athlete'), position, status('pending'|'accepted'|'declined'|'expired'|'revoked'), valid_until?, invited_by?, decided_at?, reason?`；`UNIQUE(account_id, org_id)`。
邀请状态机：`pending → accepted / declined / expired / revoked`（PRD §9）。
### role_permissions（权限字典，种子维护，运行期只读）
`role TEXT, resource TEXT, action TEXT, data_scope('self'|'own_org'|'granted_scope'|'platform'|'all')`；复合主键。解析规则见 03-权限矩阵。
### audit_logs（审计，只增不改）
`id, actor_account_id, actor_identity_type, org_id?, client('app'|'pc'|'server'), action, resource_type, resource_id, before JSON?, after JSON?, reason?, created_at`
### idempotency_keys（幂等）
`key TEXT, account_id, endpoint, request_hash, response_status, response_body JSON, created_at`；主键 `(account_id, endpoint, key)`；命中重放返回原响应（Header `Idempotency-Replayed: true`）。
### outbox_events（跨端可靠通知）
`id, event_type, payload JSON, target_account_id?, dispatched_at?, created_at`；业务事务同写，后台泵投递为 notifications；失败不回滚业务事实。

## 3. 体育项目域（核心主数据，含版本历史）

### sports_projects
`id, name, name_en?, slug UNIQUE, intro, source, status('draft'|'active'|'deprecated'), version`
删除策略：仅软停用（deprecated），不物理删除（PRD §14）。
### project_categories / project_tags
`id, name UNIQUE`；链接表 `project_category_links(project_id, category_id)`、`project_tag_links(project_id, tag_id)` —— **多对多**。
### project_branches（分支）
`id, project_id FK, name`（如 摔跤→自由式/古典式）。
### competition_units（竞赛小项）
`id, branch_id FK, name(如 男子自由式68kg), gender?, group_name?, rule_version`。
### project_relations（业务↔项目多对多）
`id, project_id FK, entity_type('profile'|'content'|'course'|'competition'|'org'), entity_id`；`UNIQUE(project_id, entity_type, entity_id)`。
### project_versions（主数据变更历史）
`id, project_id FK, version, change_summary, actor_account_id, snapshot JSON(变更前全量), created_at` —— 每次 PATCH 生成一条。

## 4. 人员档案域

### person_profiles
`id, account_id FK, kind('athlete'|'coach'|'mentor'), title, bio, region, achievements JSON, career JSON, mentor_info JSON?(等级占位名·规则待确认), verify_status('verified'|'unverified'|'pending'|'appealing'), visibility JSON(隐私字段公开范围), version`
### profile_project_links
`profile_id FK, project_id FK, is_primary`。
### follows
`id, account_id FK, target_type('profile'|'project'|'org'|'content'), target_id, created_at`；`UNIQUE(account_id, target_type, target_id)`。
### mentorships（师徒关系，与身份分离）
`id, mentor_account_id FK, mentee_account_id FK, kind('student'|'coach'), status('active'|'ended'), since, version`
### authorizations（授权，显式挂接关系）
`id, mentorship_id FK, grantor_account_id, grantee_account_id, scope_project_id?, scope_content?, scope_region?, term_start, term_end, allow_sub_grant INT, parent_authorization_id?, status('draft'|'submitted'|'approved'|'rejected'|'active'|'expired'|'revoked'), version`
状态机（PRD §9）：`draft → submitted → approved|rejected → active → expired|revoked`。

## 5. 教学训练域

### courses
`id, name, mentor_account_id FK, org_id?, format('offline'|'online'), audience, outline JSON, sessions, region, status('draft'|'pending_review'|'published'|'paused'|'archived'), version`
### course_project_links(course_id, project_id)
### classes（班级）
`id, course_id FK, name, schedule, capacity, status('open'|'closed')`
### enrollments（课程报名）
`id, course_id FK, class_id?, account_id FK, status('pending'|'approved'|'rejected'|'cancelled'|'completed'), decided_by?, decided_at?, reason?, version`；`UNIQUE(course_id, account_id)`。
状态机：`pending → approved|rejected|cancelled → completed`。
### attendance
`id, class_id FK, enrollment_id FK, occurred_on, status('present'|'absent'|'leave'), recorded_by`；`UNIQUE(class_id, enrollment_id, occurred_on)`。
### training_plans / training_records
`training_plans: id, account_id(学员), mentor_account_id, course_id?, title, items JSON, period, version`
`training_records: id, plan_id FK, account_id, content, metrics JSON, occurred_on, recorded_by, version`

## 6. 赛事域

### competitions
`id, name, organizer_org_id FK?, date_start, date_end, location, intro, quota, status('draft'|'pending_review'|'published'|'registration_closed'|'in_progress'|'completed'|'cancelled'), version`
状态机（PRD §9）：`draft → pending_review → published → registration_closed → in_progress → completed|cancelled`。
### competition_project_links(competition_id, project_id)
### registrations（赛事报名）
`id, competition_id FK, account_id FK, status('pending'|'approved'|'rejected'|'cancelled'), decided_by?, decided_at?, reason?, version`；`UNIQUE(competition_id, account_id)`。
### competition_schedules（赛程）
`id, competition_id FK, unit_name, phase, start_at, venue`
### results / result_revisions（成绩，修订留版本）
`results: id, competition_id FK, account_id FK, unit_name, rank, score, source(成绩来源), status('provisional'|'confirmed'), confirmed_by?, version`
`result_revisions: id, result_id FK, before JSON, after JSON, reason, actor_account_id, created_at` —— 客户端不得直接覆盖已确认成绩。
### selections（选拔）
`id, competition_id FK, account_id, target, status('nominated'|'selected'|'dropped'), note?`

## 7. 内容与榜单域

### contents
`id, type('video'|'article'), title, summary, author_account_id FK, media_url?, status('draft'|'pending_review'|'published'|'offline'), published_at?, views/likes/favs/comments INTEGER(服务端计数), version`
### content_project_links(content_id, project_id)
### comments
`id, content_id FK, account_id FK, body, status('visible'|'hidden'), created_at`
### reactions
`id, content_id FK, account_id FK, kind('like'|'fav')`；`UNIQUE(content_id, account_id, kind)`。
### ranking_definitions / ranking_snapshots
`ranking_definitions: id, category('athlete'|'mentor'|'project'|'course'|'event'|'org'|'city'), mode('overall'|'pro'|'popularity'), formula JSON(指标与权重口径), period('week'|'month'|'total'), status` —— 综合榜权重 6:4 为**演示口径**，入种子数据并标注，正式规则待确认。
`ranking_snapshots: id, definition_id FK, period_key, rows JSON, computed_at` —— 存储真实来源与统计口径、更新时间。

## 8. 消息、设置与媒体域

### notifications
`id, account_id FK, category('system'|'interact'|'biz'|'mentorship'), kind(course|event|mentorship|auth|system|follow|like|comment), title, body, biz_ref_type?, biz_ref_id?, read_at?, created_at` —— 由业务事件经 Outbox 生成，**不手写**。

### settings（五作用域，版本控制）
`id, account_id FK, scope('account'|'privacy'|'notify'|'org'|'device'), org_id?, device_id?, prefs JSON, version, updated_at`；`UNIQUE(account_id, scope, org_id, device_id)`。
优先级：账号/隐私/通知为账号范围共享；组织级只影响本组织、**不覆盖个人级**；设备级（推送令牌/会话/本机生物识别）不跨端。读取时服务端按 scope 合并返回并标注来源。

### media_files（本地 Demo 媒体）
`id, owner_account_id, filename, mime, size, storage_path(server/data/uploads/…), status`；统一经 `GET /v1/media/:id` 鉴权返回。接云端时仅替换存储适配层，业务模型不变。

### schema_migrations
`version TEXT PK, applied_at` —— `up` 成功后记录；`down` 回滚后删除行。
