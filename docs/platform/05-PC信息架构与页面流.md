# 05 · PC 信息架构与页面流（形态 B：业务管理工作台 V1）

> 视口：1440×900 与 1920×1080 同信息层级自适应（非固定画布放大）。视觉：国际体育科技风，沿用 `#12345B / #2872B8 / #F3F6FA / 白卡片`，AntD5 ConfigProvider 定制主题（主色 #12345B、交互蓝 #2872B8、底色 #F3F6FA、圆角 8–10px）。**商城、商品、支付、商家入驻不出现。**

## 1. 主框架

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏 56px：品牌标识 · 全局搜索 · 通知(角标) · 帮助 ·          │
│           [组织切换 ▾] [身份切换 ▾] · 个人菜单(设置/登出)     │
├──────────┬─────────────────────────────────────────────────┤
│ 左侧导航  │  主内容区（面包屑 / 页面标题 / 操作区）            │
│ 220px    │  列表页：搜索·筛选·排序·分页·列配置·批量动作·导出   │
│ 可折叠   │  详情页：基本资料/关联项目/关系/业务记录/状态历史/日志 │
│ 64px    │  全部页面覆盖：加载/空/错误/无权/确认与撤销反馈       │
└──────────┴─────────────────────────────────────────────────┘
```

- 左侧导航由 `GET /me` 返回的权限摘要**生成**，无权模块不显示（服务端仍逐请求校验，前端隐藏仅为体验）。
- 组织/身份切换 → `POST /auth/context` 换发上下文令牌 → 清缓存 → 回工作台首页。
- 自适应规则：1440 基准单列工作区 + 表格 8–10 列；1920 时表格列数放宽、卡片网格 3→4 列、侧栏默认展开；`<1366` 侧栏自动折叠。

## 3. 关键页面流

- **登录→进入**：`/login` → `POST /auth/sessions` → 多组织/多身份时弹选择层 → `POST /auth/context` → `/` 工作台。
- **报名审核闭环（阶段4 验收主路径）**：APP `POST /registrations` → PC 赛事详情"报名审核"待办出现（workbench 待办+列表红点）→ PC `approve/reject`（可批量，展示数量/影响/失败明细，敏感二次确认）→ Outbox → APP 收到通知、报名状态更新；反向（课程报名→PC 审核）同构。
- **列表页统一交互**：关键词搜索 + 筛选 + 排序 + 分页 + 列配置 + 批量动作（有权才显示）+ 导出（单独授权）+ 空态/错误态；批量审核不可静默执行。
- **详情页统一分区**：基本资料 / 关联项目 / 人员组织关系 / 业务记录 / 状态历史与操作日志；面包屑 + 返回列表。
- **编辑保护**：必填/格式/跨字段校验；未保存离开提醒；并发 409 → 提示最新版本并允许刷新重试。
- **可访问性**：颜色不作唯一状态标记（配图标/文字）、键盘可达弹层与表单、图表附文本摘要。

## 4. 状态语义（全端统一，来自服务端状态机）

组织成员：`pending→accepted/declined/expired/revoked`；资质：`draft→submitted→under_review→approved/rejected→resubmitted`；课程：`draft→pending_review→published→paused/archived`；报名：`pending→approved/rejected/cancelled→completed`；赛事：`draft→pending_review→published→registration_closed→in_progress→completed/cancelled`；授权：`draft→submitted→approved/rejected→active→expired/revoked`。状态变更均记录操作者/时间/原因/前后状态（详情页"状态历史"直接读 audit_logs）。
