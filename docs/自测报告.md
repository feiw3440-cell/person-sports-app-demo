## 5. v2 自测中发现并已修复的缺陷

| # | 缺陷 | 修复 |
|---|---|---|
| 1 | **发现页白屏**（v1 遗留逻辑残留：空查询返回 undefined） | 移除 searchAll('') 调用，改用内容常量；回归通过 |
| 2 | **综合榜分数取整**：周期缩放 Math.round(98.5)=99 导致综合分 9900（原型 9850），且掩盖了缓存问题排查 | scaleByPeriod 在总榜不缩放；overall 分数保留两位小数 |
| 3 | **陈旧 dev server 进程霸占 5173 端口**：旧 vite 进程未随任务终止而退出，模块图陈旧导致"改码不生效"假象 | 清理孤儿进程并以 --strictPort 重启；建立"改码后验证"流程 |
| 4 | 分类 tile"教练与导师"文字换行；作者名截断；身份行"当前：xxx"换行 | 字号 10.5px、头像 24px、nowrap 等细节修正 |
| 5 | 1:1 改版后身份工作台入口丢失（首页工作台条随原型移除） | 工作台入口收敛到身份管理页当前身份行（管理/机构/教练/学员/运动员均可达） |
