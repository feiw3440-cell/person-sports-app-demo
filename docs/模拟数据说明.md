# 专体 Demo · 模拟数据说明

> PRD §9.3 要求：所有模拟账号、成绩、排名、互动量、审核状态、赛事和课程均须明确标注为"演示数据"或"模拟数据"；不得伪造真实认证、真实比赛成绩或平台已核实的事实。本文件说明每类模拟数据的范围与呈现方式。

## 1. 数据总则

- 数据源：`app/src/data/db.ts`（本地常量）+ `app/src/services/api.ts`（榜单/搜索计算），无任何网络请求。
- 持久化：仅**用户操作产生的本地状态**（当前身份、关注/点赞/收藏、消息已读、申请状态演示值）存于浏览器 localStorage（键 `zhuan-ti-demo`）；清除浏览器数据即恢复初始演示状态。
- 商城实体：**不存在**。无商品/商家/订单/购物车/佣金等任何数据结构。

## 3. 交互产生的本地状态（也属演示）

- 关注/点赞/收藏切换、消息已读、导师申请状态演示控制（审核中/补充材料/已通过/已驳回）。
- 身份切换仅改 `currentRoleId` 指针——验证方式：切换身份后回到"我的"，关注/收藏/授权数据不变。

## 4. 未来接真实数据时的边界

`services/api.ts` 的函数签名（`buildRanking` / `searchAll` / `feedOfFollowed` 等）即为未来真实 API 的替换边界：组件不直接读 `db.ts` 的榜单计算逻辑，替换后端时仅需改写 services 层。商城相关实体届时作为独立扩展加入，不与本 Demo 数据结构混合。
